Guía Rápida de URLs

YouTube Live

Pega el link normal del directo o del video. El sistema lo convierte solo.

https://www.youtube.com/watch?v=XXXXX https://youtu.be/XXXXX

Twitch

Pega el link de tu canal. El sistema genera el embed automáticamente.

https://www.twitch.tv/tucanal

HLS (OBS / Cámara IP)

Usa la URL .m3u8 de tu servidor de streaming (Nginx, Wowza, etc).

https://servidor.com/stream.m3u8
